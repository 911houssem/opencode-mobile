# OpenCode Mobile

نسخة موبايل (Android / iOS) من OpenCode — تطبيق Expo/React Native يتصل بخادم OpenCode على جهاز الكمبيوتر الخاص بك عبر الشبكة.

## الفكرة

التطبيق لا يضمّ محرك OpenCode نفسه، بل يتصل بخادم OpenCode يعمل على جهازك باستخدام أمر الـ serve، ويعرض الجلسات والمحادثة مباشرة على هاتفك (بثّ حي، أدوات، أذونات، تبديل موديل/وكيل).

## المتطلبات

- Node.js 22.13 أو أحدث على الكمبيوتر
- الهاتف والكمبيوتر على نفس شبكة الـ WiFi
- تطبيق **Expo Go** على الهاتف (من App Store أو Google Play)

## 1) تشغيل خادم OpenCode على الكمبيوتر

افتح مجلد مشروعك في الطرفية ثم:

```bash
bun dev
```

أو لتشغيله كخادم يكتشفه التطبيق تلقائيًا (الخيار الموصى به — بدون إدخال أي عنوان):

```bash
bun run opencode serve --port 4096 --mdns
```

- `--mdns` يجعل الخادم يُعلن عن نفسه باسم `opencode.local` في الشبكة، فيجده التطبيق تلقائيًا عند فتحه.
- فعّل الحماية بكلمة مرور إذا أردت (Basic Auth) — وإن فعلت أدخلها مرة واحدة فقط داخل التطبيق.

> ملاحظة: جرّب فتح العنوان من متصفح على الهاتف للتأكد أن الشبكة تصل إلى الخادم.

## 2) التشغيل الكامل على الهاتف (Termux)

بدون كمبيوتر — الخادم والتطبيق يعملان على هاتفك نفسه عبر **Termux** (يتطلب هواتف aarch64 وتثبيت Termux من **F-Droid** وليس من متجر Play).

1. تثبيت Termux من F-Droid ثم فتحه وتحديثه:
   ```bash
   pkg update -y && pkg upgrade -y
   ```
2. تفعيل الوصول للتخزين (اختياري، للمشاريع خارج بيئة Termux):
   ```bash
   termux-setup-storage
   ```
3. نسخ التطبيق وتجهيز كل شيء (يثبّت Node.js و OpenCode natively لـ Termux):
   ```bash
   git clone https://github.com/911houssem/opencode-mobile.git
   cd opencode-mobile
   bash termux/install.sh
   ```
4. إعداد مفاتيح مزوّد الذكاء الاصطناعي — أنشئ ملف `~/.config/opencode/opencode.json` أو عرّف متغيرات بيئة مثل:
   ```bash
   export ANTHROPIC_API_KEY=sk-ant-...
   # أو OPENAI_API_KEY / GEMINI_API_KEY ...
   ```
5. افتح **نافذة Termux جديدة** (سحب من اليسار → New session) للخادم:
   ```bash
   cd ~/opencode-mobile && bash termux/server.sh
   ```
   سيبدأ الخادم على `http://localhost:4096`.
6. افتح **نافذة Termux جديدة** للتطبيق:
   ```bash
   cd ~/opencode-mobile && bash termux/app.sh
   ```
7. ثبّت تطبيق **Expo Go** من المتجر، افتحه، واكتب:
   ```
   exp://127.0.0.1:8081
   ```
8. عند فتح التطبيق سيبحث عن الخادم تلقائيًا (نفس الهاتف أو شبكة LAN) ويقترب منك بلا أي إدخال. إن لم يجد شيئًا اضغط زر **"Search for server (automatic)"** أو أدخل العنوان يدويًا.

> لإبقاء العمليتين تعملان عند إغلاق الشاشة استخدم `tmux`/`screen` أو `termux-wake-lock` عند الحاجة.

## 2) تشغيل التطبيق

من مجلد `opencode-mobile`:

```bash
npm install
npx expo start
```

افتح كاميرا الهاتف وامسح رمز QR الظاهر في الطرفية (يتطلب تطبيق Expo Go). أو اكتب:

```bash
npx expo start --android   # على جهاز محاكي Android
npx expo start --ios       # على Mac مع محاكي iOS
```

## 3) الإعداد داخل التطبيق (اكتشاف تلقائي)

عند فتح التطبيق يبحث تلقائيًا عن خادم OpenCode بالترتيب:
1. على الهاتف نفسه (`localhost`) — أسرع حالة (Termux).
2. عبر الشبكة باسم `opencode.local` (عند تشغيل الخادم بـ `--mdns`).
3. فحص الشبكة المحلية (LAN) بحثًا عن المنفذ 4096.

أغلب الحالات يتصل مباشرة **بدون إدخال أي عنوان**. شاشة الإعداد اليدوي تبقى فقط كخيار احتياطي (زر "Search for server" يعيد البحث في أي وقت).

بعد الاتصال يمكنك:

- عرض الجلسات وإنشاء جلسة جديدة (زر +).
- فتح جلسة ومحادثة مباشرة مع بثّ حي للرد.
- التوقف أثناء التشغيل (زر الإيقاف □).
- تبديل الوكيل/الموديل (زر ⚙ أعلى المحادثة).
- الموافقة على طلبات الأذونات (Allow / Once / Reject).

```
src/
  api/        أنواع ومكوّن عميل REST + اتصال SSE (الأحداث الحية)
  store/      حالة التطبيق (الإعدادات، الجلسات)
```
